    Platform Features

    Every security check QR Shield performs — and what it looks for

    Core
    📷
    Live QR Scanner
    Real-time camera scanning using html5-qrcode. Supports front/rear cameras, auto-focus, and instant decode on any QR code.
    Core
    🔒
    SSL / TLS Validation
    Checks for HTTPS presence, certificate validity, expiration date, and self-signed or mismatched certificates.
    Intel
    🔗
    Redirect Chain Tracing
    Follows the full redirect chain up to 10 hops. Flags URL shorteners, suspicious intermediate domains, and redirect loops.
    Intel
    📅
    Domain Age Analysis
    WHOIS-based domain registration check. Newly registered domains (under 30 days) are strong phishing indicators and scored accordingly.
    Analysis
    🎭
    Typosquatting Detection
    Pattern-matches against 50+ known brand impersonation templates. Catches character substitution (paypa1, g00gle) and fake subdomains.
    Analysis
    🌍
    GeoIP Lookup
    Resolves server IP to country, ASN, and hosting provider. Flags bulletproof hosting regions and high-abuse TLDs like .xyz, .tk, .ru.
    Threat
    🛡️
    Threat Intelligence
    Checks URLs against phishing feeds, malware C2 lists, and spam blacklists. Integrates with VirusTotal and Google Safe Browsing APIs.
    Threat
    💉
    URL Parameter Analysis
    Scans query parameters for credential-harvesting patterns, injection attempts, and suspicious keywords used in phishing attacks.
    Report
    📊
    Risk Score Engine
    Weighted multi-factor scoring from 0–100. Each check contributes a risk weight. Final score drives verdict: Safe / Suspicious / Malicious.
    Report
    📄
    JSON Export & SIEM
    Full JSON report export per scan. Includes all check results, redirect chain, timestamp, and risk breakdown — ready for SIEM ingestion.
    Dashboard
    📋
    Scan History & Stats
    Persistent scan history with statistics dashboard. Track total, safe, suspicious, and malicious scan counts across sessions.
    API
    ⚡
    FastAPI Backend
    Production-ready Python FastAPI backend with full Swagger docs, CORS support, and modular threat analysis engine. Deployable on any cloud.
